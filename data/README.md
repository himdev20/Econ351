# Data

The course datasets were distributed by the instructor and are **not redistributed** in this repository. Place the files below in this folder, using exactly these names, before running the code.

| File | Used in | Description |
|---|---|---|
| `igg.xlsx` | HW1 Q1 | Serum IgG concentration (g/L) and age for 298 children aged 6 months to 6 years |
| `marijuana.xlsx` | HW1 Q2–Q4 | Pew Research Center survey (March 2013) on marijuana legalization, 1,240 respondents |
| `EducationalAttainment.xlsx` | HW1 Q5 | Educational attainment (4 levels) with family background covariates |
| `cola.xlsx` | HW2 Q2 | Stacked brand-choice data for Pepsi / 7-Up / Coke: `id, choice, price, feature, display` |
| `FMD.xlsx` | HW2 Q3 | Foot-and-mouth disease cases by Turkish province, 1998: `EasternTurkey, FMD1998, Cattle` |
| `Aptitude.xlsx` | HW3 Q2 | 200 students: `read, math, prog, apt` (apt censored at 800) |
| `mroz.xlsx` | HW3 Q3 | Mroz (1987) married women's labour supply. Sheets `Data` and `Desc` |
| `jtrain2.xlsx` | HW3 Q4 | NSW job-training experiment, 445 men. Sheets `Data` and `Desc` |
| `Murder.xlsx` | HW4 Q3 | US state murder rates, executions and unemployment, 1987/1990/1993. Sheets `Data` and `Desc` |

`mroz`, `jtrain2` and `murder` are standard Wooldridge textbook datasets. They are also available in the R package [`wooldridge`](https://cran.r-project.org/package=wooldridge) and the Python package `wooldridge`.
